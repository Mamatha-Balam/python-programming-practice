## 🧠 Key Learnings

### 1. What is a Dictionary?

* A collection of key-value pairs
* Defined using curly braces {}

---

### 2. Features of Dictionaries

* Keys are unique
* Values can be of any data type
* Mutable (can be modified)

---

### 3. Accessing Values

* Values are accessed using keys

Example:
student["name"]
