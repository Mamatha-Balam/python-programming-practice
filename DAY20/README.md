## 🧠 Key Learnings

### 1. Modifying Dictionary

* Values can be updated using keys

Example:
student["gpa"] = 4.0

---

### 2. Adding New Key-Value Pair

* New data can be added dynamically

Example:
student["university"] = "XYZ University"

---

### 3. Dictionary Methods

* keys() → returns all keys
* values() → returns all values
* pop() → removes a key-value pair

---

### 4. Checking Key Existence

* Use `in` keyword to check if key exists
