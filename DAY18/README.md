## 🧠 Key Learnings

### 1. What is a Tuple?

* A collection of items like a list
* Defined using parentheses ()
* Immutable (cannot be modified)

---

### 2. Features of Tuples

* Ordered collection
* Supports multiple data types
* Faster than lists in some cases

---

### 3. Tuple Packing & Unpacking

* Packing → storing values in a tuple
* Unpacking → assigning tuple values to variables

---

### 4. Tuple Functions

* len() → length of tuple
* min() → smallest value
* max() → largest value

---

### 5. Tuple Operations

* Concatenation using +
* Repetition using *
