## 📖 Topics Covered

* Function calls within functions

---

## 🧠 Key Learnings

### 1. Default Parameters

* Provide default values to function arguments
* Used when no value is passed

---

### 2. Calling Functions Inside Functions

* Functions can call other functions
* Helps in code reuse and modular design

---

### 3. Scope of Variables

* Global variables → accessible everywhere
* Local variables → accessible only inside function

---

## ⚠️ Important Note

* Local variables cannot be accessed outside the function
* Improper scope handling leads to errors
