## 🧠 Key Learnings

### 1. Positional Arguments

* Values are passed based on order
* Order must match function parameters

---

### 2. Keyword Arguments

* Values are passed using parameter names
* Order does not matter

---

### 3. Default Values

* Parameters can have default values
* Used when no argument is passed
